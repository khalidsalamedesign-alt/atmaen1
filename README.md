# اطمئن — موقع الإسعافات الأولية والطوارئ المنزلية

موقع ثابت مبني بـ [Astro](https://astro.build)، يشتغل بدون إنترنت بعد أول زيارة (PWA).
الخطة الكاملة: [plan.md](plan.md)

## التشغيل

```bash
npm install
npm run dev        # تطوير: http://localhost:4321
npm run build      # بناء النسخة النهائية في dist/
npm run preview    # معاينة النسخة المبنية
```

## أين كل شيء

| المسار | المحتوى |
|---|---|
| `src/data/cases/*.json` | **الحالات** — ملف لكل حالة. الموقع يولّد الصفحات منها |
| `src/data/countries.json` | أرقام الطوارئ لكل دولة + الدولة الافتراضية |
| `src/data/taxonomy.ts` | التصنيفات والفئات العمرية |
| `src/layouts/Base.astro` | الشريط العلوي، التذييل، وضع الطوارئ، اختيار الدولة |
| `src/pages/case/[id].astro` | قالب صفحة الحالة |
| `src/styles/global.css` | نظام التصميم (الألوان والخطوط) |
| `src/components/Icon.astro` | الأيقونات |
| `src/pages/tools/` | المؤقّتات، خريطة الجسم، بطاقة العائلة |
| `src/pages/printables/` | الملصقات المطبوعة (تسحب الخطوات من ملفات الحالات) |
| `src/pages/sw.js.ts` | Service Worker — يتولّد مع كل بناء |

## إضافة حالة جديدة

1. انسخ أي ملف من `src/data/cases/` وغيّر اسمه والـ `id` بداخله (إنجليزي، بشرطات).
2. عبّئ الحقول. `keywords` مهمة للبحث — اكتب الكلمات العامية اللي يكتبها الناس.
3. `icon` لازم يكون اسم موجود في `Icon.astro`.
4. `related` لازم تشير لـ `id` حالات موجودة.
5. `npm run build` — الصفحة تظهر تلقائياً بالبحث والتصنيف والفئة العمرية و sitemap.

## اعتماد حالة بعد المراجعة الطبية

كل الحالات حالياً `"status": "draft"` وتعرض «مسوّدة — لم تُراجع طبياً بعد».
بعد ما يراجعها المختص:

```json
"source": { "name": "اسم المرجع", "url": "https://..." },
"status": "reviewed",
"reviewedAt": "2026-10"
```

الحالة المعتمدة تعرض تلقائياً «راجعه مختص · التاريخ». غير المعتمدة لا تعرض أي علامة — لذلك **لا تنشر قبل اعتماد كل الحالات**.

## رسومات الخطوات

الرسومات في `src/illustrations/*.svg` وتُدمج داخل الصفحة (تتلوّن تلقائياً بالوضع الليلي).
أضف اسم الملف بدون الامتداد للخطوة:

```json
{ "text": "...", "detail": "...", "illustration": "back-blows" }
```

الألوان عبر كلاسات: `il-bg` `il-skin` `il-a` (المصاب) `il-b` (المُسعف) `il-arrow` `il-label` — ولاحقة `-s` للخطوط.
الموجود حالياً: الإنعاش، وضعية الإفاقة، ضربات الظهر، ضغطات البطن، ضربات ظهر الرضيع، ضغطات صدر الرضيع، الضغط على النزيف، تبريد الحرق.

## صور المشاركة وأيقونات التطبيق

```bash
npm run build
npm run preview      # في نافذة
npm run images       # في نافذة ثانية — يستخدم Edge/Chrome
npm run build        # لنسخ الصور الجديدة
```

يولّد `public/og/*.png` (صورة لكل حالة) و `icon-192.png` و `icon-512.png` و `apple-touch-icon.png`.
أعد تشغيله بعد تعديل عنوان أي حالة.

## ملف المراجعة الطبية

```bash
npm run review
```

يولّد `review/medical-review-packet.html` من ملفات الحالات: غلاف لبيانات المراجع والمرجع المعتمد،
ولكل حالة جدول بكل بند (صحيح / يحتاج تعديل / ملاحظات) وخانة اعتماد وتوقيع، وملحق للتحقق من أرقام الطوارئ.
افتحه بالمتصفح ← اطبع ← حفظ PDF ← أرسله للمراجع.

## الاستضافة

أي استضافة ملفات ثابتة. ارفع محتوى مجلد `dist/` بعد `npm run build`. لازم HTTPS حتى يشتغل الأوفلاين.

| الاستضافة | ملف الإعداد (جاهز داخل `public/`) |
|---|---|
| Cloudflare Pages / Netlify | `_headers` — كاش الملفات، أمان، sw.js بدون كاش |
| Hostinger / Apache / LiteSpeed | `.htaccess` — HTTPS إجباري، روابط بدون .html، صفحة 404، ضغط |

**Cloudflare Pages:** أمر البناء `npm run build` — مجلد الإخراج `dist`.
